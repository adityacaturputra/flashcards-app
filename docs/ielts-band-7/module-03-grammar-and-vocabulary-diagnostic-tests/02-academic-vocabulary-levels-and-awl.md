## 🔄 2. Tabel Transformasi Kosakata Umum ke AWL

Gunakan tabel konversi ini sebagai rujukan mengganti kata-kata klise dalam tulisan dan ucapan Anda:

| Kosakata Umum (Band 5–6) | Padanan Akademis AWL (Band 7+) | Contoh Penggunaan Kontekstual |
| :--- | :--- | :--- |
| *Big difference* | **Disparity / Divergence** | *"A pronounced **disparity** exists between urban and rural educational infrastructure."* |
| *Speed up* | **Accelerate / Hasten** | *"Unregulated exploitation has **hastened** the extinction of endangered fauna."* |
| *Wipe out completely* | **Annihilate / Obliterate** | *"The epidemic virtually **annihilated** the indigenous population."* |
| *Clear / Obvious* | **Evident / Manifest** | *"It is increasingly **evident** that proactive intervention is warranted."* |
| *Dangerous / Risky* | **Hazardous / Perilous** | *"Indiscriminate waste disposal poses **hazardous** consequences to marine biomes."* |
| *Make worse* | **Exacerbate / Aggravate** | *"Economic stagnation will inevitably **exacerbate** social inequality."* |
| *Show / Prove* | **Demonstrate / Substantiate** | *"Empirical data **substantiates** the efficacy of renewable energy adoption."* |

> [!TIP]
> **Kuasai Kolokasi, Bukan Sekadar Sinonim**: Jangan menghafal kata secara terisolasi! Hafalkan kata bersama pasangannya, misalnya: *profound disparity*, *hasten the demise of*, *substantiate a claim*.
