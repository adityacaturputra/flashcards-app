## 🎯 1. Landasan Konseptual: Karakteristik Ujian Cambridge Seri 16 Modern

Cambridge IELTS Buku 16 mencerminkan standar mutakhir ujian IELTS saat ini, di mana ritme dialog terasa sangat cair (*natural flowing dialogue*) dengan penekanan tinggi pada **spesifikasi teknis, ukuran bahan, dan penyesuaian pesanan kustom**.

Dalam percakapan ini, seorang pelanggan menelepon staf perusahaan percetakan untuk memesan brosur dan materi promosi acara. Topik ini menguji ketelitian pendengaran dalam menangkap rincian material kertas, jumlah eksemplar cetak, format pengiriman file digital, serta tenggat waktu penyelesaian.

## ⚡ 3. Jebakan Distraktor Utama Cambridge 16 Test 2

### Jebakan 1: Tekstur Kertas (*Paper Finish Distractor*)
* **Mekanisme Audio**: Staf percetakan mendiskusikan opsi: *"We usually recommend a glossy surface for flyers, but since these are professional brochures with long text, a matte finish is much easier on the eyes."*
* **Taktik Eliminasi**: Pelanggan menanggapi: *"Yes, let's go with the matte option then."* Jawaban tepat adalah `MATTE` (atau `MATT`). Kata `GLOSSY` gugur sebagai opsi penolakan.

### Jebakan 2: Jumlah Eksemplar Cetak (*Quantity Discrepancy*)
* **Mekanisme Audio**: Pelanggan awalnya menyebut angka perkiraan (*"We were thinking of printing three hundred"*), namun setelah staf memberitahu adanya diskon untuk pemesanan lebih besar, pelanggan memutuskan memesan `500` eksemplar.
* **Taktik Eliminasi**: Kunci angka akhir yang disepakati setelah penawaran diskon: `500`.

### Jebakan 3: Format File Logo (*Digital File Format*)
* **Mekanisme Audio**: Pembicara menyebut format umum seperti *JPEG* atau *PNG*, namun staf menegaskan bahwa untuk cetak resolusi tinggi mereka memerlukan file vektor atau file `PDF`.
* **Taktik Eliminasi**: Dengarkan syarat teknis yang diminta oleh staf percetakan.

## 🏛️ 4. Kaidah Baku Format Lembar Jawaban

* **Ejaan Tekstur Bahan**: `MATTE` atau `MATT` (keduanya diterima oleh Cambridge).
* **Batas Kata Tunggal**: Tulis hanya 1 kata atau 1 angka per celah (`500`, `MATTE`, `PDF`).
* **Format Huruf Kapital**: Tulis seluruh jawaban dalam huruf besar untuk memastikan kejelasan dokumen cetak.
